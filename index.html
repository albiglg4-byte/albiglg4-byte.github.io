SpeedShorts Clip Bot

SpeedShorts Clip Bot is a desktop application for Windows that runs on the owner's own computer.

  • It edits Twitch and Kick stream clips into vertical short videos: subtitles, hook text, censored profanity.
  • The owner connects their own TikTok accounts with TikTok Login Kit (desktop authorization).
  • Finished videos are uploaded to the connected accounts with the TikTok Content Posting API (Direct Post), about one video per hour, with an automatically generated title and hashtags.
  • Every video can be previewed in a local panel before it is queued.

The app has no servers. Access tokens and videos are stored only on the owner's computer.
